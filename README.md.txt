# 📊 Big Mart Retail Analytics Dashboard

## 📌 Project Overview
The Big Mart Retail Analytics Dashboard is an interactive Power BI project designed to explore and analyze retail data. It provides meaningful insights into product categories, outlet characteristics, fat content, and item pricing through interactive visualizations.

## 🎯 Project Objectives
- Analyze retail product information.
- Understand product distribution across different outlets.
- Explore item types and fat content.
- Create an interactive dashboard for data exploration.
- Present insights using charts, KPIs, and filters.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Visualization

## 📂 Dataset Information
- Dataset: Big Mart Sales Dataset
- Total Records: 5,681
- Total Columns: 11

## 📈 Key Performance Indicators (KPIs)
- Total Records: 5,681
- Average Item MRP: 141.02
- Maximum Item MRP: 266.59
- Minimum Item MRP: 31.99

## 📊 Dashboard Features
- Item Type Analysis
- Fat Content Analysis
- Outlet Type Analysis
- Outlet Location Analysis
- Interactive Slicers and Filters
- Multiple Data Visualizations

## 💡 Key Learnings
- Data cleaning and transformation using Power Query.
- Designing interactive dashboards in Power BI.
- Working with retail datasets.
- Creating meaningful data visualizations.
- Understanding exploratory data analysis.
